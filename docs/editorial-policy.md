# 编纂说明

## 我写什么

我根据国家机构公开的资料写事件叙述。每个事件写清时间、地点、人物和经过；来源里明确说到的原因和结果，我也会写进去。我不写自己的判断、评价和推测。

每条事件有元数据、叙述、原文摘录、来源和原文链接。叙述是我写的，原文摘录是来源里的原话。

## 我怎么写

叙述里的数字、日期、地名、人名要和原文一致。每条叙述后面注明用了哪些来源。

官方对事件的评价，我放在“原文摘录”里，不写进叙述。

如果叙述和原文不一致，以原文为准，并改过来。

## 收哪些事件

我先收全国性事件。省级事件只收影响全国或意义典型的，县级及以下一般不收。每条至少有一个中央国家机构、国家馆藏或国家媒体的来源。

官方来源说法不一致时，我把原文并列，不替它们下结论。

## 用哪些来源

我用中央国家机构、国家馆藏、国家媒体和国家科研机构的公开资料，也会用经过审核的地方党史办、地方志办、地方政府网站和地方党报。

个人博客、自媒体、百科、商业聚合和非官方转载不用。

## 原文和版权

- 政府文件、法律、公报、白皮书可以全文转载，并保存本地快照。
- 国家媒体的报道只摘录，附原文链接，不整篇转载。
- 图书只引短段，标页码和版本。
- 档案给馆藏号和目录链接；没有在线全文的，注明需要到馆查阅。
- 图片只用公有领域或已授权的。

## 时间范围

1840—2021。2021 年以后只做大事件记，另行核对。

## 纠错

如果引文、日期、地名、链接或机构信息有错，请在 GitHub 提 Issue，或从勘误页发我原文链接。我会改，并更新条目的复核日期。
