# 编纂原则

## 定位

本站以国家机构公开资料为限，提供导览式叙述、元数据、原文摘录与原文链接。导览可以连贯、可读、细节化，但只作描述，不加入作者判断和评价，也不超出所引资料；导览与原文明确区分。

## 叙述边界

- 允许：整体性描述、细节叙事、背景介绍、来源中明确陈述的因果、结构性串联、适度文学化表达。
- 必须：每个事实性陈述都能在所引来源中找到依据；导览段末标注来源；关键数字、日期、地名、人物与原文一致。
- 禁止：作者自己的判断、意义总结、价值评价、因果推断；编造细节、对话、心理活动与场景；把导览文字冒充原文；用修辞改变事实。
- 官方评价：只放在“原文摘录”中，不写入导览。
- 冲突：导览与原文不一致时，以原文为准，并在勘误中修订。

## 收录标准

- 全国性事件优先；省级只收具有全国影响的事件；县级及以下只收具有全国影响或典型意义者。
- 每条至少一个中央国家机构、国家馆藏或国家媒体来源；核心条目尽量提供两个以上独立来源。
- 官方来源之间如有差异，并列保留原文与出处，不作裁断。

## 来源范围

中央国家机构、国家馆藏、国家媒体、国家科研机构，以及经审核列入白名单的地方党史办、地方志办、地方政府网站与地方党报。

不收录：个人博客、自媒体、百科、商业聚合、非官方转载。

## 原文与版权

- 政府文件、法律、公报、白皮书：可全文转载并保存本地快照。
- 国家媒体报道：有限摘录 + 官方原文链接，不整篇镜像。
- 正式出版物：短引文 + 页码/章节 + 版本信息 + 馆藏或出版社链接。
- 档案：馆藏号 + 目录链接；无在线全文时标注“需到馆查阅”。
- 图片：仅公有领域或已授权素材。

## 时间范围

1840—2021。2021 年以后仅作大事记式延伸，另行复核。

## 勘误

以原文为准。修订保留版本记录，并更新条目的“最后复核”日期。
