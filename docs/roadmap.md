# 内容扩充计划

## 现在做到哪一步

- 详解：10 条，覆盖 1840—1978。
- 大事记：1012 条，覆盖 1919—2021，来自《中国共产党一百年大事记（1921年7月—2021年6月）》。
- 国史：733 条，来自《中华人民共和国大事记（1949年10月—2019年9月）》。
- 前编：23 条，补 1841—1918 年。
- 编年：1251 条（党史、国史去重后）；地图：786 条有地点匹配。
- 来源：12 个。
- 目标：1000 条以上详解。

## 怎么做

1. 从大事记里挑重点条目。
2. 为条目补官方来源、原文摘录、地点、人物和组织。
3. 写 3—6 段叙述，只写来源里的事实。
4. 用 `npm run build` 检查日期、来源、引文和字段。
5. 每批 20 条，完成后更新本页。

## 质量要求

- 每条至少一个中央国家机构、国家馆藏或国家媒体来源。
- 叙述里的数字、日期、地名、人名和原文一致。
- 官方评价放在“原文摘录”里，不写进叙述。
- 叙述里不写我自己的判断、评价和推测。
- 大事记条目保持原文摘录，不改写。
