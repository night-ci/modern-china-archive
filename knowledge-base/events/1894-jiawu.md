# 甲午战争

- 时间：1894年—1895年
- 地点：山东威海；辽东半岛
- 人物：李鸿章
- 组织：日本、清朝、北洋舰队

## 叙述

1894年7月25日，日本为实现其侵占朝鲜和中国的野心，偷袭在朝鲜牙山口外丰岛的清朝军舰，拉开甲午战争的序幕。随后，朝鲜政府请求清政府出兵，帮助镇压东学党领导的大规模农民起义。日本为了对外扩张，以保护侨民为名乘机进攻朝鲜，进而向清政府挑衅。

8月1日，中日双方正式宣战。因李鸿章坚持避战静守的消极方针，清军十分被动。日军很快攻陷平壤，然后由海陆两线直逼中国，清北洋舰队全军覆没，辽东半岛陷落。

1895年，日本迫使清政府签订《马关条约》。中国被迫割弃台湾，向日本支付2.3亿两白银的巨额赔款，其中3000万两作为赎回辽东半岛的偿金；日本还得到了西方列强在华已有的一切特权。

这场战争发生在光绪二十年至二十一年（1894—1895年），是日本侵略朝鲜与中国的战争。
